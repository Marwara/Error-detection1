Methods of Error Detection

Data gets corrupted in transmission more often than you'd think. This workbook covers the methods computers use to catch — and sometimes even fix — the damage.

1

Key vocabulary

Open each card before starting the Lab — the calculators and the quiz use these terms without re-explaining them.

Parity check +
An extra parity bit is added to a block of data so the total count of 1-bits matches an agreed rule. With even parity, the total number of 1s (including the parity bit) must be even. With odd parity, it must be odd. If a single bit is corrupted in transit, the count's parity flips and the error is detected.
data 1010001 (three 1s) + even parity bit 1 → 10100011 (four 1s, even)
Parity block (2D parity) +
Arrange data as a grid and calculate a parity bit for every row and every column. A single corrupted bit will fail exactly one row's check and exactly one column's check — and the row and column meet at exactly one cell. This means a parity block can not only detect a single-bit error but locate and correct it, which a simple parity check cannot do.
row 2 fails + column 3 fails → the error must be at row 2, column 3
Checksum +
The sender adds up the values in a block of data to produce a single checksum value, which is sent along with the data. The receiver repeats the same calculation on the data it received; if the two checksums don't match, an error has occurred somewhere in the block.
checksum = sum of all data values (often reduced using modulo)
Check digits +
A check digit is an extra digit calculated from the other digits in a code (like a barcode or ID number) and attached to the end. It is recalculated when the code is used, to catch mistakes such as a mistyped or transposed digit — common in human data entry.
barcodes, ISBNs, bank account numbers all use check digits
Modulo-11 check digit +
Each digit is multiplied by a descending weight, the products are summed, and the sum is divided by 11. The remainder is subtracted from 11 to give the check digit (if the result is 11, use 0; if it's 10, use the letter X). Because each position has a different weight, this method can detect transposition errors (two digits swapped) that a simple sum-based checksum would miss.
check digit = 11 − (weighted sum MOD 11)
ISBN-13 check digit +
Every book's 13-digit ISBN ends with a check digit calculated from the first 12. Each digit is multiplied by an alternating weight of 1 and 3, the products are summed, and the check digit is whatever must be added to reach the next multiple of 10 (sum MOD 10, subtracted from 10).
check digit = (10 − (weighted sum MOD 10)) MOD 10
Echo check +
The sender transmits data to the receiver, which immediately sends ("echoes") it straight back. The sender compares the echo to what it originally sent; a mismatch means an error occurred and a retransmission is requested. Simple, but it roughly doubles network traffic and can't correct the error itself.
sender → receiver → echo back → sender compares

Exam-style challenge

(a) Calculation. A 7-bit code 1010001 is to be transmitted using even parity. Calculate the parity bit and state the full 8-bit code that would be transmitted.

Show a model answer for part (a) 
Step 1 - Count the 1-bits in 1010001
  1,0,1,0,0,0,1 -> three 1-bits (an odd number)

Step 2 - Even parity needs the TOTAL count of 1-bits to be even
  three is odd, so the parity bit must be 1 (making the total four, which is even)

Step 3 - Transmitted code = data bits + parity bit
  1010001 + 1 = 10100011

(b) Calculation. Using the modulo-11 method with weights 7, 6, 5, 4, 3, 2, calculate the check digit for the 6-digit code 834196.

Show a model answer for part (b) 
Step 1 - Multiply each digit by its weight
  8x7=56, 3x6=18, 4x5=20, 1x4=4, 9x3=27, 6x2=12

Step 2 - Sum the products
  56+18+20+4+27+12 = 137

Step 3 - Divide by 11 and find the remainder
  137 / 11 = 12 remainder 5

Step 4 - Check digit = 11 - remainder
  11 - 5 = 6

The code transmitted would be 8341966.

(c) Discuss. Explain why a parity block (2D parity) can correct a single-bit error, while a simple single parity check can only detect that an error has occurred.

Show a model answer for part (c)
A single parity check only tells you that the overall count of 1-bits no longer matches the expected parity — it has no way of knowing which bit, out of potentially many, caused the problem. A parity block adds a parity bit for every row and every column. A single corrupted bit will cause exactly one row's parity check to fail and exactly one column's parity check to fail. Since only one cell lies at the intersection of that specific row and that specific column, the position of the error is uniquely identified, so it can simply be flipped back — correcting the error rather than just detecting it.
